# Grapher research

This directory contains experiments that consume or evaluate Grapher without automatically becoming Grapher runtime behavior.

## Active studies

- [`training-data/`](training-data/) — whether normalized Grapher records can be transformed into auditable evaluation/training examples, and which extraction/quality policies are reliable.

Research findings may motivate Grapher changes only when they reveal a general work-graph deficiency. Model-specific conveniences remain downstream.
